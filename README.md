## 📋 Projects List  

### 1. 🪯 FlipCard    
- **[🔗 Repository](https://github.com/kalios-01/FlipCard)**  
- [![Google Play](https://upload.wikimedia.org/wikipedia/commons/7/78/Google_Play_Store_badge_EN.svg)](https://play.google.com/store/apps/details?id=com.kaliostech.flipcard)  

#### ✨ Description  
FlipCard is a fun and engaging memory-based card game where players flip over pairs of cards to find matching ones. The game is designed with an intuitive and interactive UI, making it enjoyable for both casual and competitive players. It includes multiple features to enhance gameplay experience, such as:  

- **Single-player and two-player modes**: Play alone or challenge a friend.  
- **Card skin selection screen**: Choose from various card designs to personalize the experience.  
- **Time Bonus feature**: Earn extra points based on how quickly you find all matches.  
- **Smooth animations and sound effects**: Enhances the overall gaming experience.  
- **Scoring system**: Tracks player performance for competitive fun.  

#### 📚 Learning Outcomes  
While developing FlipCard, I gained experience in:  
- **State management in Flutter** using Provider.  
- **UI/UX design** with Flutter widgets and animations.  
- **Game logic implementation** for matching card pairs efficiently.  
- **Performance optimization** to ensure a smooth experience on all devices.
